HERO IMAGE
==========

Drop your home-page hero photo here, named exactly:

    hero.jpg

Guidelines:
- Landscape orientation, ideally 2000px+ wide.
- Optimize it to roughly 300-600 KB (a huge file slows the page).
  Free tool: https://squoosh.app  (drag in, export as JPG ~75% quality).
- A darker / nighttime Strip shot works best with the site's dark theme,
  but the CSS overlay keeps the gold headline readable over any photo.

IMPORTANT — only use an image you own or have licensed:
- Best & safest: a still frame from your own Vegas drone b-roll.
- Do NOT use random photos found online on a public site (copyright risk).

Once hero.jpg is in this folder, the home page hero picks it up automatically.
