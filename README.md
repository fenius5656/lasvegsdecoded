# Vegas Decoded — Website

A fast, static website for the Vegas Decoded YouTube channel. No servers, no
database, **$0/month hosting**. New videos sync in automatically; each episode
can also become a 2–4 minute blog-style **Post**.

- **Videos** — pulled automatically from your channel's public YouTube feed.
- **Posts** — hand-crafted (or script-generated) HTML reads, styled to the brand.
- **Cost** — hosting is free on GitHub Pages. Only optional cost is a domain (~$10–15/yr).

---

## What's in here

```
index.html            Home page (latest videos + posts)
videos.html           All videos (auto-synced)
posts.html            All posts index
posts/                One HTML file per post
  _TEMPLATE.html      Copy this to start a new post
assets/
  css/style.css       Brand styling (from your Brand Kit)
  js/config.js        ← YOUR settings live here (channel URL, domain)
  js/main.js          Renders video/post cards
data/
  videos.json         Auto-generated by the sync job (don't edit by hand)
  posts.json          Index of posts (add an entry per new post)
scripts/sync_videos.py        The video fetcher (runs on GitHub, not your PC)
.github/workflows/sync-videos.yml   Scheduled job that runs the fetcher
```

## One-time setup (about 15 minutes)

### 1. Set your details
Open `assets/js/config.js` and set:
- `channelUrl` — your channel, e.g. `https://www.youtube.com/@VegasDecoded`
- `siteUrl` — your domain, e.g. `https://vegasdecoded.com`

Open `data/videos.json` and set `"channelId"` to your channel ID
(starts with `UC…`). To find it:
1. Go to your channel page → **… / Share channel → Copy channel ID**, or
2. Visit <https://www.youtube.com/account_advanced> while logged in.

### 2. Put the code on GitHub (free)
1. Create a free account at <https://github.com>.
2. Create a new **public** repository named `vegas-decoded-website`.
3. Upload this whole folder (drag-and-drop works in the GitHub web UI:
   *Add file → Upload files*), or use git:
   ```bash
   git init
   git add .
   git commit -m "Initial site"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/vegas-decoded-website.git
   git push -u origin main
   ```

### 3. Turn on free hosting (GitHub Pages)
1. In the repo: **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Branch: **main**, folder: **/ (root)** → **Save**.
4. Wait ~1 minute. Your site is live at
   `https://YOUR_USERNAME.github.io/vegas-decoded-website/`.

### 4. Turn on auto-sync for videos
The workflow in `.github/workflows/sync-videos.yml` runs every 6 hours.
- To run it immediately: **Actions** tab → **Sync YouTube videos** → **Run workflow**.
- It reads the `channelId` you set in `data/videos.json`. (Optionally, set a repo
  **Variable** named `VD_CHANNEL_ID` under *Settings → Secrets and variables →
  Actions → Variables* to override it.)

### 5. Connect the custom domain — lasvegasdecoded.com (Namecheap)

The `CNAME` file in this repo already contains `lasvegasdecoded.com`. The domain is
registered at **Namecheap** and currently points to Replit (`34.111.179.208`). To move
it to GitHub Pages:

1. In the repo: **Settings → Pages → Custom domain**, enter `lasvegasdecoded.com`, Save.
2. Log in to **Namecheap → Domain List → lasvegasdecoded.com → Manage → Advanced DNS**.
3. **Delete** the existing records that point to Replit:
   - the `A Record` for host `@` → `34.111.179.208`
   - the `A Record` (or `CNAME`) for host `www` → Replit
4. **Add** these records instead:
   | Type | Host | Value | TTL |
   |------|------|-------|-----|
   | A Record | @ | 185.199.108.153 | Automatic |
   | A Record | @ | 185.199.109.153 | Automatic |
   | A Record | @ | 185.199.110.153 | Automatic |
   | A Record | @ | 185.199.111.153 | Automatic |
   | CNAME Record | www | YOUR_USERNAME.github.io. | Automatic |
5. Save. DNS usually updates within 30 min (can take a few hours).
6. Back in **Settings → Pages**, wait for the check to pass, then tick **Enforce HTTPS**.

> Note: this replaces the Replit-hosted site at the domain. Your Replit project still
> exists; only where the domain points changes.

## Adding a new post

1. Copy `posts/_TEMPLATE.html` to `posts/your-slug.html`
   (slug = lowercase-with-dashes, e.g. `best-cheap-eats-strip.html`).
2. Fill in the title, description, tags, date, body, and the episode `VIDEO_ID`
   in the embed.
3. Add an entry to the top of the `posts` array in `data/posts.json`:
   ```json
   {
     "slug": "your-slug",
     "title": "Your Post Title",
     "excerpt": "One-line teaser shown on cards.",
     "date": "2026-08-15",
     "readTime": "3 min read",
     "tags": ["Hotels"],
     "cover": ""
   }
   ```
4. Commit/push. The post appears on the home page and `/posts.html` automatically.

> Tip: your existing **Vegas Decoded script** workflow can generate the post
> body straight from an episode script — paste it into the template.

## Local preview (optional)

You don't need any tools to edit files, but to preview locally with working
`fetch()` you need a tiny web server. If you install Python:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>. (Opening the HTML files directly with
`file://` will show the pages but the video/post cards won't load, because
browsers block `fetch()` on `file://`.)
